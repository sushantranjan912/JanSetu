# 🌍 What is JanSetu?

**JanSetu** is a collaborative civic innovation platform designed to crowdsource societal challenges and connect them with the right **people, institutions, expertise and resources** required to solve them.

The platform creates a structured bridge between:

```text
        👨‍👩‍👧 Citizens
              │
              ▼
        🏛️ Administration
              │
              ▼
        🎓 Universities
              │
              ▼
        👨‍💻 Student Teams
              │
              ▼
        🤖 AI Matching
              │
              ▼
        🏭 Industries
              │
              ▼
       🌱 Real-World Impact
```

Instead of treating a societal problem as just a complaint, JanSetu turns it into a **structured problem-solving opportunity**.

---

# 🎯 Problem Statement

### **Smart India Hackathon 2026 — SIH26043**

> **“A digital platform to crowdsource societal challenges and facilitate collaborative problem solving through universities and industry partnerships.”**

Across communities, many genuine problems exist in areas such as:

- Education
- Healthcare
- Agriculture
- Water management
- Sanitation
- Environment
- Rural livelihoods
- Accessibility
- Urban infrastructure
- Public services

However, there is often a disconnect between:

**The person facing the problem**  
↓  
**The institution capable of solving it**  
↓  
**The industry capable of supporting the solution**

JanSetu aims to bridge this gap through a single collaborative digital ecosystem.

---

# 💡 Our Solution

JanSetu establishes a structured lifecycle for every societal challenge.

```text
Problem Identified
       ↓
Citizen Submission
       ↓
Admin Validation
       ↓
University Assignment
       ↓
Student Team Formation
       ↓
Solution Development
       ↓
Proposal & Resource Requirements
       ↓
AI-Based Industry Matching
       ↓
Industry Collaboration
       ↓
Implementation
       ↓
Social Impact
```

### The core philosophy:

> **Don't just report problems. Connect problems with people capable of solving them.**

# ⭐ Key Features

## 👨‍👩‍👧 1. Citizen Portal

Citizens are the starting point of the ecosystem.

They can:

- Submit real-world societal problems
- Provide detailed descriptions
- Upload supporting images/videos/evidence
- Categorize problems
- Provide relevant contextual information
- Track submitted problems
- Monitor the progress of their reported challenges

### Citizen → Problem

```text
Identify
   ↓
Describe
   ↓
Provide Evidence
   ↓
Submit
   ↓
Track
```

---

# 🏛️ 2. Admin Portal

The administration acts as the **central coordination layer**.

Admins can:

- Review submitted problems
- Validate genuine problems
- Reject invalid submissions
- Categorize challenges
- Assign problems to relevant universities
- Review university solution proposals
- Review funding and resource requirements
- Coordinate industry collaboration
- Manage the complete problem lifecycle

### Admin Workflow

```text
Citizen Problem
      ↓
Admin Review
      ↓
 ┌────┴────┐
 ▼         ▼
Reject    Approve
            ↓
      Assign University
```

---

# 🎓 3. University Portal

Universities transform validated societal problems into practical solutions.

A university lead/professor can:

- Receive assigned challenges
- Create student teams
- Assign students to projects
- Develop solution proposals
- Define technical requirements
- Specify required raw materials
- Estimate funding requirements
- Define implementation requirements

### University Workflow

```text
Assigned Problem
       ↓
Professor / University Lead
       ↓
Student Team
       ↓
Research & Ideation
       ↓
Solution Proposal
       ↓
Resources & Requirements
```

This creates an opportunity for students to work on **real-world problems rather than only theoretical projects**.

---

# 🏭 4. Industry Portal

Industries bring the resources and expertise required to move promising solutions toward implementation.

Industry participation can include:

- Technical expertise
- Mentorship
- Technology
- Raw materials
- Funding
- Infrastructure
- Domain knowledge
- Implementation support

Industries can be connected with university proposals according to their **expertise and capabilities**.

---

# 🤖 5. AI-Based Industry Matching

One of JanSetu's major innovations is its proposed **AI-powered industry matching system**.

Instead of relying entirely on manual searching, JanSetu can compare:

### University Requirements

```text
Domain
Technology
Skills
Raw Materials
Funding
Infrastructure
Expertise
```

with:

### Industry Capabilities

```text
Industry Domain
Technical Expertise
Available Technology
Resources
Experience
Capabilities
```

The system can then identify industries that are semantically relevant to the proposed solution.

### AI Matching Pipeline

```text
University Proposal
        ↓
Requirement Extraction
        ↓
Text Processing
        ↓
Semantic Representation
        ↓
Industry Capability Representation
        ↓
Similarity Analysis
        ↓
Ranking
        ↓
Relevant Industry Matches
```

### AI / ML Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Sentence Transformers
- Semantic Similarity

---

# 🧠 Why AI Matching?

Consider a university developing a solution for:

> **Smart irrigation for water-scarce agricultural regions**

The project may require:

```text
IoT Sensors
Solar Power
Agricultural Expertise
Embedded Systems
Water Management
Funding
```

Instead of manually searching hundreds of organizations, the matching engine can identify industries whose capabilities align with these requirements.

This makes collaboration:

**Faster → More Relevant → More Scalable**

# 🔐 Security Architecture

JanSetu follows a role-based authentication approach.

```text
                    Authentication
                          │
                          ▼
                       JWT Token
                          │
                          ▼
                  Role Verification
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
       CITIZEN           ADMIN        UNIVERSITY
                                          │
                                          ▼
                                       INDUSTRY
```

Security mechanisms include:

- JWT-based authentication
- Password hashing using bcrypt
- Role-based authorization
- Protected API routes
- Environment-based configuration
- Backend-side validation

### 🔒 Security Rule

Sensitive information such as:

```text
Database credentials
JWT secrets
API keys
Passwords
```

must always remain inside environment variables and **must never be committed to GitHub**.

# ⚙️ Getting Started

## Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm
- MongoDB / MongoDB Atlas
- Git
- Python 3.x for AI components

---

## 1. Clone the Repository

```bash
git clone https://github.com/sushantranjan912/JanSetu.git

cd JanSetu
```

---

## 2. Configure Environment Variables

Create `.env` files based on `.env.example`.

Example:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
PORT=5000
```

**Never commit `.env` files.**

---

## 3. Install Dependencies

For the backend:

```bash
cd backend
npm install
```

For the required frontend applications:

```bash
cd citizen
npm install
```

Repeat for the required modules.

---

## 4. Start the Backend

```bash
npm run dev
```

or:

```bash
npm start
```

---

## 5. Start the Frontend

Inside the relevant frontend directory:

```bash
npm run dev
```

The application will be available on the local development server.
